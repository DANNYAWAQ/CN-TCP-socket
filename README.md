# CN-TCP-socket
ccd lab assignment

How to run
Open two terminals in the same folder.
Terminal 1 — Server:
python server.py

Terminal 2 — Client:
python client.py

For the calculator:
Terminal 1:
python server_math.py

Terminal 2:
python client_math.py

Enter:
5 + 3

Output:
Result: 8.0

Important: Start the server first, then run the client. Both programs use 127.0.0.1:8080, so they communicate through your own computer.
